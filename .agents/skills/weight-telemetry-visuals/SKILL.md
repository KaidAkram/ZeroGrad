# Weight Telemetry Visuals

Validate telemetry with src/zerograd/telemetry.py and replay checksums. Use scripts/report.py for figures/cards and scripts/render_video.py for frame-based media. Never invent compilation accuracy checkpoints. Preserve folded-coordinate and schematic-geometry labels. Inspect portrait and wide frames, then run scripts/verify_media.py. Exact SVG variants are editable sources, not claims of identical raster composition.
