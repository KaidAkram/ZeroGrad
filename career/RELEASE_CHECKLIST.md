# Before publishing

- Run release-check; resolve FAIL and read all WARN entries.
- Configure actual repository URL and author metadata.
- Inspect mobile studio and video at feed size.
- Confirm captions, alt text, license inventory and artifact checksums.
- Publish repository first, then use its real link in the post.
- Upload actual video/poster, add concise relevant tags and an evidence-linked pinned comment.
- Never advertise unrun semantic or real-model results.
- Posting, messaging and deployment remain manual.
